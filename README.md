## 📌 Project Overview

This project focuses on analyzing online retail sales transaction data to understand business performance and generate actionable, data-driven insights.

The project follows an end-to-end data analytics workflow:

**Raw Data → Data Cleaning → Data Transformation → KPI Analysis → Exploratory Analysis → Power BI Dashboard → Business Insights → Recommendations**

The objective is to help a business understand:

- Revenue performance
- Sales trends over time
- Top-performing products
- Top-performing countries
- Customer activity
- Order performance
- Average order value
- Potential business growth opportunities

---

## 🎯 Business Problem

Businesses generate large amounts of transactional sales data, but raw data alone does not provide useful decision-making information.

This project transforms raw online retail transaction records into meaningful business metrics and visualizations.

The analysis aims to answer the following questions:

1. What is the total revenue generated?
2. How many orders were placed?
3. How many units were sold?
4. How many unique customers are present?
5. How many unique products are sold?
6. Which products generate the most revenue?
7. Which countries generate the most revenue?
8. How does revenue change over time?
9. What is the average order value?
10. What actions can the business take to improve sales performance?

# 📂 Dataset

The project uses the **Online Retail Dataset**, which contains transaction-level information from an online retail business.

### Dataset Attributes

| Column | Description |
|---|---|
| InvoiceNo | Unique invoice/transaction number |
| StockCode | Unique product code |
| Description | Product description |
| Quantity | Number of units purchased |
| InvoiceDate | Date and time of transaction |
| UnitPrice | Price per unit |
| CustomerID | Unique customer identifier |
| Country | Customer's country |
